전송 데이터 M(x) = 101101001

                        1 0 1 0 0 1 0 1 0

체크섬      : 00010   (교재 정답 00010 -> 일치)
송신 데이터 : 10110100100010   (교재 정답 10110100100010 -> 일치)

======================================================================
2. 송신 -> 전송 선로 -> 수신 시연
======================================================================
상황                          수신 데이터            나머지     판정
오류 없음                       10110100100010    00000   정상 수신
3번 비트 반전                    10100100100010    10001   오류 검출!
0,5번 비트 반전                  00110000100010    10001   오류 검출!
G(x) 배수 오류(검출 실패 예)         00100000100010    00000   정상 수신
※ 오류 패턴 자체가 G(x)로 나누어떨어지면 CRC는 오류를 검출하지 못한다.
